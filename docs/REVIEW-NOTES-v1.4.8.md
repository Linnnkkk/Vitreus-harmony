# Vitreus 1.4.8 审核说明

## 自定义笔记库位置

新增「自定义笔记库位置」（会员功能）：用户可以把本地笔记库放到本设备任意文件夹，便于搭配其他同步工具。

- 入口在「其他配置 → 笔记库 → 笔记库位置」；会员可更换位置，恢复默认位置始终免费。
- 会员权益只限制「更换位置」这个设置动作；已设置的位置在会员到期后仍照常读写，不会自动切回默认目录。
- 目录由用户通过系统文件夹选择器选取，应用只在该用户选择的目录内读写笔记文件，不扫描其他目录，不把笔记内容上传到 Vitreus 托管服务。
- 更换笔记库位置会清空本设备上已授权的 AI 库授权（换根后同名库已是另一份笔记），但保留已配对设备。
- 目录授权失效时明确报错并停止启动，不会静默回退到沙箱默认目录或旧目录。

## 新增系统权限

- `ohos.permission.FILE_ACCESS_PERSIST`：用于持久化用户选择的笔记库目录授权，使应用重启后仍可读写该目录；属受限 ACL 权限，发布签名 Profile 已包含对应 ACL 声明。
- 未新增网络、位置、相机、剪贴板等其他权限；未引入统计、崩溃收集、广告或推送 SDK。

## WebDAV 子目录修复

- 修复部分 WebDAV 服务（如坚果云）在 `Depth: infinity` 只返回根层时，子文件夹内容加载不出来的问题：按服务端实际返回行为探测，确认目录树不完整时才降级为逐目录 `Depth: 1` 扫描。
- 不针对特定服务商写特例；对能返回完整目录树的服务仍沿用原有快路径。
