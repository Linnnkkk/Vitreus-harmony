# Vitreus 1.4.2 更新说明

1. 新增 WebDAV 远程库（会员功能）：直接打开支持webdav协议的服务器中的vault，读写自动连接云端，省去手机与云端之间的手动同步，打开即用，让跨设备使用笔记更省心。
2. 界面优化：调整主页与设置页面布局，优化点击体验和过渡动画。

本版正在准备提交应用市场；商店实际可下载版本与审核进度以应用市场页面为准。

## 使用入口

- 主页「打开 Vault」打开本设备笔记库，左下角「配置远程库」设置 WebDAV。
- 速记和网页剪藏切换「远程库」后，可选择「库名 · WebDAV」。
- 已有 Ignis 服务使用「连接已有服务器」。浏览器和 AI 访问设备笔记在「与其他设备连接」区域管理。
- 启动偏好、笔记库与保存规则在「其他配置」中展开设置；更换组件包置顶显示。

WebDAV 需要自备服务和存储空间，不包含在会员费用内。多设备同时修改同一文件仍可能覆盖；本功能减少手动同步操作，不承诺并发编辑无冲突。连接配置改变后按页面提示完全退出应用再重开。
