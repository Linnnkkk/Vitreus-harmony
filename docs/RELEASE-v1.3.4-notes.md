# Vitreus 1.3.4 — 会员页合规补全与客服入口

**Vitreus 1.3.4**（versionCode 1000013）根据应用市场审核反馈补全会员购买页的自动续费说明与客服联系方式。内嵌服务无变化。

| Item | Version |
|---|---|
| HarmonyOS | 6.0.2(22)+ · phone / tablet / 2in1 |
| Embedded server | ignis 0.8.16-mod（bundle v22，无变化） |
| Obsidian components | 1.12.7 / 1.13.7（均支持） |
| Vitreus | 1.3.4 / versionCode 1000013 |

> Obsidian 组件包由用户自备。Vitreus 不包含、不分发 Obsidian 受版权保护的内容。

## 变更

- **会员页自动续费说明显著展示**：方案下方新增说明卡片，写明包月/包年自动续费的扣费时间、价格以收银台为准、可在「设置 → 华为账号 → 付款与购买 → 订阅」取消；购买按钮下方同步提示。
- **新增《自动续费服务协议》**：点击即可在应用内阅读完整条款（服务内容、价格与扣费、取消方式、退款、权益说明、客服方式）。
- **新增客服联系方式**：会员页「客服与反馈」与关于页「客服与反馈（GitHub Issues）」均直达 <https://github.com/Linnnkkk/Vitreus-harmony/issues>。
