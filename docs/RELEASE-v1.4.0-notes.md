# Vitreus 1.4.0

- 优化启动与页面返回，减少重复跳转。
- 改善伺服器模式与 AI 连接的状态同步及后台运行处理。
- AI 连接新增脱敏诊断信息复制，方便排查连接问题。
- 会员页新增可展开说明的功能对照表，统一功能名称。
- 首页「快捷捕获」入口更名为「配置」。

本版继续保留局域网 AI 连接：提供19个 MCP 工具，支持搜索、读取笔记及标签、属性、链接、待办和大纲查询；获得授权后可编辑并恢复备份。电脑端需安装 MCP 连接器，教程见 App。

## 版本信息

- 应用：1.4.0 / versionCode 1000019。
- 内嵌服务：ignis 0.8.18-mod.4，bundle v38。
- Obsidian 组件兼容范围：1.12.7–1.14.4；第三方插件以实际兼容性为准。
- 当前 npm 连接器：`@liiink/vitreus-ai-connector@1.3.9-beta.1`。本仓库连接器的后续改动尚未发布至 npm，更新 App 不会自动更新电脑端连接器。

1.4.0 已发布，实际可下载版本以商店页面为准。
