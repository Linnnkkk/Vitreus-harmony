## 变更

- 改善笔记内容尚未缓存时的搜索性能，批量读取内容并重试失败的预取请求。
- 修复部分插件网络请求的 Content-Type 传递问题。
- 修复直连主机设置未对部分插件请求生效的问题。
- 重新整理速记卡片：事项 / 待办改为格式选择，添加时间可独立开关；正文无需填写列表标记，保存前可预览格式。草稿同时保留本次格式选择。
- 分享和速记的保存提示明确标注设备本地库，避免在远程模式下误以为内容已经写入服务器。本版不新增远程捕获写入能力。

Obsidian 组件版本未变，无需重新导入组件包。
