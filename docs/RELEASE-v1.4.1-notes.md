# Vitreus 1.4.1 更新说明

本版聚焦启动与记录体验，正在准备提交应用市场。商店是否已提供更新，以应用市场页面为准。

- 可在配置页开关“记住上次使用的模式”
- 本地启动界面更简洁
- 记住上次选择的本地或远程保存位置，不再影响应用的启动模式
- 可清除服务器配置，修复部分情况下已保存密码丢失的问题。
- 改善启动时切到后台再返回的恢复体验，提升部分插件网络请求的兼容性。

清除服务器配置不会删除已有笔记、草稿或未完成的捕获记录。首次导入、重新导入及故障排查仍可使用完整的运行管理入口。

## 分享到今日笔记

纯文字分享已经支持通过会员「自定义存储规则」追加到当天文件：选择「写进日记」预设，再按自己的笔记库调整路径、标题并保存。默认示例为 `日记/{{今天}}.md` 和 `## 速记`；日期变量固定为 `yyyy-MM-dd`，不会自动读取 Obsidian 的日记设置。

网页剪藏正文保存为独立 Markdown 文件，日记只追加链接索引。本版不将此行为改为整篇网页正文内嵌，也不宣称自动适配任意日记插件。

## 版本信息

- 应用：1.4.1 / versionCode 1000020。

- Obsidian 组件兼容范围：1.12.7–1.14.4，无需因本轮修改重新导入组件。
