# Vitreus 1.3.8 — 远程速记与网页剪藏

**已发布：用户真机验证通过远程速记、网页剪藏、服务器配置与卡片透明度；撤销重试与更新弹窗待最终确认。**

| Item | Version |
|---|---|
| Vitreus | 1.3.8 / versionCode 1000017 |
| Embedded server | ignis 0.8.18-mod.3（bundle v32） |
| Obsidian components | 1.12.7 – 1.14.4（沿用） |

## 本轮范围

- 修复关于页进入「支持作者」「隐私政策」时过渡泛白的问题。
- 修复本地模式下第三方插件「检查更新」误报网络未连接：Obsidian 依据 `navigator.onLine` 判断，本地壳 WebView 内该值可能为 false，导致请求根本不发出。现在兼容层固定为在线，真实失败仍由请求本身报错。
- 修复中文账号无法登录伺服器：浏览器按 UTF-8 发送用户名，服务端却按 latin1 解析，导致口令校验始终不匹配、反复弹登录框。现在两种编码都接受，英文账号与错误密码行为不变。
- 远程模式缓存插件与主题文件：读取时带 ETag 条件请求，内容未变直接复用本机缓存，不再每次打开都重新下载；笔记正文与配置不进入该缓存。
- 为远程服务器模式接入速记与网页剪藏，保留自定义文件路径、标题插入、事项/待办、时间选择、剪藏正文和索引能力。
- 远程登录、选库、断网与失败恢复需要用户真机验证，不能把本地模拟测试视为 NAS 实测。

## 当前验证版边界

- 速记和分享可在当前页面选择本地或远程目标；服务器配置统一保存在远程入口，账号密码通过本机系统保险箱保存。
- 深色认证框提示字更清晰；速记成功对勾约 260ms 完成，约 480ms 后开始退出。
- 修复打开速记/分享卡片时整屏闪黑：这两个页面是透明窗口，遮罩原先从完全透明淡入、离场又淡出到 0，首末帧露出窗口黑底。现在遮罩全程可见，卡片离场只轻微缩小，不再整块透明。
- 常用方案只修改涉及的规则，变量点击复制到剪贴板，不再自动改输入框。
- 插件持久缓存已接入启动预加载，仅在服务器确认未变时复用。外部远程服务器需要部署更新才能生效，仅升级手机 App 不会更新外部服务。
- 连接官方 IGNIS 时，手机端不再额外插入缓存层：本轮尝试的客户端加速经真机验证命中率始终为 0（官方页面的加载时序会让缓存判断持续失效），未能带来实际提速，已整体撤除，避免留下无效代码与误导。连接官方 IGNIS 的加载速度目前与官方实现一致，未做加速。
- 远程服务器地址改为保存到本机配置文件，App 关闭后再用速记/分享也能读到；地址与账号直接在捕获设置页填写，不再为了配置而打开网页。
- 目前只支持服务器根地址部署，不支持 `/ignis/` 等反向代理路径前缀；不支持时明确拒绝，不请求错误的根服务。
- 指定标题与撤销使用读取核对、修改和回读确认。现有 NAS API 没有条件写入/CAS，核对和写入之间仍有并发覆盖窗口；本版只允许独立测试库、无其他设备同时编辑时验证，不能视为已完成安全对等。
- 撤销仅在相关内容未变化时执行，不能把“拒绝覆盖后续编辑”描述为无条件撤销成功；撤销失败会保留重试入口，不再把按钮锁死。
- 发布前复查移除了无调用方的 `RemoteCapture.launch` 与整套草稿队列机制，以及旧的 `RemoteCapturePage` 确认页（已被同页选择取代）。
- ArkTS 调试构建已通过；本轮界面与剪贴板行为仍待用户真机验收。自动化测试不是这些验收的替代。
- 客户端插件加载加速本轮未达成，相关代码与调试入口已移除；不宣称连接官方 IGNIS 的加载速度有任何改善。
- 客户端侧插件复用依赖官方服务器的文件元数据（修改时间与大小）判断是否变化，这不是内容级校验；官方服务器若先返回旧索引再后台刷新，理论上存在短暂给出旧插件文件的时间窗，因此不宣称强一致。

## 验收重点

- 本地模式旧行为不变。
- 远程服务器地址、笔记库和实际保存路径明确，失败不悄悄改存本地。
- 自定义文件、嵌套目录、指定标题及缺失标题的创建。
- 网页正文与索引分别确认；仅索引失败时不能重复创建正文。
- 登录过期、断网、响应丢失、重启恢复、重复点击及撤销时不误报结果。
- 原生首页与 ArkWeb 更新弹窗继续共用版本 ID 和已读状态。

## 用户真机测试顺序（待实现复核后执行）

1. 本地模式记录一条事项、一条待办，分别开关时间，确认旧库内容正确。
2. 配置远程服务器后，从速记入口进入，确认显示远程服务器与远程库，而非本地库。
3. 用独立测试笔记配置嵌套文件路径和 `## 收件箱` 标题；目标文件不存在时创建，已有标题时插入标题段末、下一个同级标题前。
4. 再试标题不存在、多个同名标题、代码块中出现同名标题、CRLF 换行的测试笔记。
5. 分享公开网页，检查正文、属性、来源、实际文件名与索引双链，索引应遵循同一指定文件和标题。
6. 测试重名不覆盖；正文保存后索引失败应仅补索引，不能重复创建正文。
7. 登录过期或杀进程后重新从小组件启动：需要认证时可见提示，正文不能丢失。
8. 断网与超时后检查结果状态；不要在真实笔记中做不确定重试测试，先用独立测试库。
9. 保存后编辑测试正文，再尝试撤销，不能删除后来修改的内容。
10. 另一个客户端同时编辑测试目标时，检查冲突处理，不把单客户端成功视作并发安全证明。
