# Vitreus 1.3.2 — 内嵌服务升级到官方 ignis 0.8.14 基线

**Vitreus 1.3.2**（versionCode 1000011）把内嵌服务从 `0.8.11-mod` 升级到 **`0.8.14-mod`**：正式并入官方 ignis 0.8.13 / 0.8.14 的 Obsidian 1.13.7 适配与修复（此前是本地手工移植的同名适配），并同步修好在 Obsidian 1.12.7 下设置面板打不开的问题。**1.12.7 / 1.13.7 双版本兼容完整保留。**

| Item | Version |
|---|---|
| HarmonyOS | 6.0.2(22)+ · phone / tablet / 2in1 |

| Embedded server | ignis 0.8.14-mod（bundle v21，基于官方 ignis 0.8.14 基线） |
| Obsidian components | 1.12.7 / 1.13.7（均支持） |
| Vitreus | 1.3.2 / versionCode 1000011 |

> Obsidian 组件包由用户自备。Vitreus 不包含、不分发 Obsidian 受版权保护的内容；请通过应用内「更换 Obsidian 组件包」导入你合法取得的官方组件包。

## ✨ 主要更新

### 内嵌服务迁移到官方 ignis 0.8.14 基线

- 内嵌服务由 `0.8.11-mod` 升至 `0.8.14-mod`（bundle v21），以官方 ignis 0.8.14 为基线重新叠加本仓库定制（LanShare、局域网鉴权、app:// 代理、鸿蒙打包、i18n 兜底等全部保留）。
- 正式并入官方 0.8.13 / 0.8.14 的 Obsidian 1.13.7 适配：启动 IPC 通道的条款与策略处理、设置面板相关守卫、窗口缩放修复。此前这些是本地手工移植的同名适配，现在与上游同一来源，后续跟随上游升级更稳。
- 版本串可在 Obsidian 界面控制台用 `window.__ignis` 查看。

### 冷启动进入 Obsidian 明显加快

- 条款握手的解析原先在每次冷启动时对整份 Obsidian 前端脚本（约 3.9MB）做完整语法树解析，手机上服务以纯解释模式运行，这一步占用主线程约 6 秒，期间网页请求全部排队，表现为进入 ArkWeb 后长时间等待。
- 现在按组件包内容哈希把解析结果缓存到本地，之后的冷启动命中缓存（毫秒级）。**导入新组件包后的第一次启动仍需解析一次**。
- 同时去掉了每次冷启动都清空并重新解压内嵌服务的步骤，改为仅在版本变化时重新部署。

### 快捷捕获重做

- **分享网页剪藏**：抓取时显示域名与三步进度，可随时改为「只存链接」；成功页展示文章标题、站点、约字数与笔记库，3 秒内可撤销；失败时按原因给出对应操作（无库去初始化、超时/保存失败可重试、无内容可关闭）。
- **笔记格式**：剪藏笔记属性对齐 Obsidian 官方网页剪藏（`title / source / author / published / created / description / tags`）；正文转为 Markdown 结构（标题、列表、粗体、链接、引用、代码块、图片、分隔线）。
- **速记**：标题行可切换笔记库，输入框随内容变高，可一键插入时间 / 标签 / 待办；取消或点空白直接保存草稿，草稿存到文件，进程被杀也不丢。
- **保存位置**：支持日期、站点等变量；提供「按日期归档 / 剪藏按站点 / 写进日记」三个常用方案一键套用，设置页实时预览路径。
- **桌面速记小组件**：颜色跟随系统深浅色。

### 平板与界面

- 修复平板上系统状态栏遮挡 Obsidian 顶部界面：Obsidian 桌面界面整体下移，侧边栏按钮一并跟随；手机版界面不受影响。
- 会员页重新设计；首页新增「快捷捕获 / 会员 / 更换组件包」入口，关于页精简为免责声明、源代码与反馈、致谢。
- 开屏画面按手机竖屏、平板/PC 横屏、接近方形三档重绘，修复平板上字标溢出与画面粗糙。
- 本地模式进入网页时显示载入提示，不再白屏。
- 更新说明弹窗改为只弹一次，主界面与网页页共用同一份已读记录。
- 修复：从网页页返回主界面偶发闪退；分享成功页对勾被裁切；「更换组件包」误改运行模式；快捷捕获设置页转场发白。

### 条款握手改为从你导入的组件包提取

- Obsidian 1.13.x 启动时会校验一段许可条款串。此前该串是硬编码常量；现在改由内嵌服务**从你导入的 Obsidian 组件包里解析真实条款串**并注入。
- 好处：换用其他版本的官方组件包时，不再需要跟着改代码；同时避免硬编码串与新版组件包不匹配导致的启动异常。
- 若组件包中确实不含该握手，会优雅跳过，不影响启动。

### 修复：Obsidian 1.12.7 下设置面板打不开

- Obsidian 1.12.x 与 1.13.x 打开设置标签页的入口不同（1.12.x 走 `display()`，1.13.x 走 `renderTab()`）。迁移过程中 1.12.x 这条路径缺失，会导致点开 Ignis 设置页报错。
- 现两条版本线各走各自入口、渲染同一份设置定义，两个版本上功能完全一致。

### 第三方插件授权策略放行继续生效

- 1.3.1 修复的「1.13.7 下第三方插件全部无法加载」在本版中保留（该修复属于上游主线，迁移时已随主线一并纳入并回归验证）。
