# Vitreus 1.3.9 — 局域网 MCP 服务器

- 支持 MCP 服务器功能，供局域网内 AI Agent 连接使用，搜索、读取笔记，并在你授权后编辑。
- 提供 19 个 MCP 工具，覆盖笔记、标签、属性、链接、待办、大纲、分段读取，以及编辑和备份恢复。
- 自主选择可访问的笔记库，默认只读；修改前自动备份，可按版本恢复。
- 本地悬浮面板支持切换伺服器与 AI 连接，两个服务可以同时运行。
- 内置多平台连接教程与可一键复制的配置指引，常显教程对应的连接器版本。
- 会员权益展示改为折叠列表，按需展开详细说明。
- 改善默认模式记忆、返回导航及两种服务页面的视觉一致性。

## 电脑连接器

需要 Node.js 20 或以上。当前连接器为预发布版本，建议先使用非重要笔记库体验。

```bash
npm install --global @liiink/vitreus-ai-connector@1.3.9-beta.1
vitreus-ai pair
```

按 App 内指引，在电脑 Agent 中注册 `vitreus-ai serve`。连接器不包含模型服务或额度。

## 使用边界

- 仅供可互通的局域网设备使用，不提供公网隧道或 App 内置 Agent。
- 选库与写入权限由用户控制；不提供删除笔记、任意 Shell 或任意插件执行。
- 首次配对材料包含短期秘密，只能通过可信方式传递，不应发布或保存到公开仓库。
- 网络隔离、防火墙或后台运行限制可能影响连接；自动发现失败时可手动更新地址。
- 条件编辑会核对读取版本，但不构成对其他同步程序或外部写入者的全局事务保证。
- 各电脑 Agent 的 PATH、命令包装器及不同操作系统兼容性，以对应客户端的实际验证为准。
