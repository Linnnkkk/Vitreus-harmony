## ✨ 新功能

### 分享速记（系统分享面板直达）

在任何应用里选中文字或链接 → 分享 → 选 **Vitreus**：内容自动落入笔记库的 `Inbox.md`，格式 `- HH:mm 内容`，全程无需打开应用。

- 毛玻璃浮层确认：保存成功打勾即走，不打断你正在做的事
- 多笔记库用户会弹出库选择，选过的库会被记住，下次直达

### 网页剪藏（链接 → 正文，不只是存个 URL）

分享一个链接过来，Vitreus 会自动抓取网页正文：

- 公众号文章、普通网页均可，正文存为 `Clippings/<日期 时间 标题>.md` 笔记，带来源 frontmatter
- `Inbox.md` 同步留一行 `[[笔记名]]` 索引，双链可点
- 抓取失败时退回保存链接本身，内容绝不丢

### 速记小组件（桌面 2x2 卡片）

桌面添加「Vitreus 速记」卡片，点击直达速记输入页：

- 输入 → 保存进 `Inbox.md` → 对勾动效自动退出，全程两三秒
- 显示保存落点，多库可点选切换

### 首次导入官方下载指引（原 1.1.2 待发内容）

首次导入向导卡片新增 Obsidian 官方获取入口（GitHub 发布页直链，应用内弱化文字链 + 跳转系统浏览器），解决"不知道去哪下 obsidian.asar"的问题。

## 🔧 问题修复（原 1.1.2 待发内容）

### 触摸板双指全局缩放禁用（issue #4-②）

平板/2in1 配键盘设备上，触摸板双指缩放会把整个 Obsidian 界面缩放（与 PDF 阅读冲突）。现已禁用网页层手势缩放，缩放交给页面自身交互。
